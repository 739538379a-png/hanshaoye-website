# 汉少爷饭团官网首页原型

首个里程碑包含移动端优先首页、响应式导航、视频首屏、产品与门店展示，以及本地模拟合作表单。

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。

如果需要稳定预览已构建版本：

```bash
npm run build
npm start
```

Windows 用户也可以双击项目根目录的 `启动官网预览.cmd`，它会启动本地服务并自动打开浏览器。预览窗口需要保持运行，关闭窗口会停止本地网站服务。

## 表单演示

表单调用本地接口，不保存或外发数据。复制 `.env.example` 为 `.env.local` 并设置 `MOCK_LEAD_ERROR=1`，可测试提交失败状态。

接口字段、校验规则和后端接入边界见 [`docs/前后端接口契约.md`](docs/前后端接口契约.md)。

## 内容边界

- 公开页面统一使用“合作”口径。
- 不包含成本、毛利、投入回报、合同、SOP 或其他内部参考资料。
- 当前未接入 CMS、CRM、地图、统计与线上部署。
