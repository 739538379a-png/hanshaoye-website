# 汉少爷饭团官网首页原型

首个里程碑包含移动端优先首页、响应式导航、视频首屏、产品与门店展示，以及本地模拟合作表单。

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。

## 表单演示

表单调用本地接口，不保存或外发数据。复制 `.env.example` 为 `.env.local` 并设置 `MOCK_LEAD_ERROR=1`，可测试提交失败状态。

## 内容边界

- 公开页面统一使用“合作”口径。
- 不包含成本、毛利、投入回报、合同、SOP 或其他内部参考资料。
- 当前未接入 CMS、CRM、地图、统计与线上部署。
