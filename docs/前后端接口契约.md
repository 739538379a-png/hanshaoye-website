# 合作咨询接口契约

## 当前接口

`POST /api/cooperation-leads`

当前实现仅用于本地演示：校验输入后返回模拟结果，不保存、不外发数据。

## 请求体

```json
{
  "name": "陈先生",
  "phone": "13800138000",
  "city": "杭州",
  "budget": "待沟通",
  "privacyConsent": true,
  "source": "homepage"
}
```

字段要求：

| 字段 | 类型 | 必填 | 规则 |
|-|-|-|-|
| `name` | string | 是 | 2—30 个字符 |
| `phone` | string | 是 | 中国大陆 11 位手机号格式 |
| `city` | string | 是 | 1—40 个字符 |
| `budget` | string | 否 | 原样传递，暂不展示数字区间 |
| `privacyConsent` | boolean | 是 | 必须为 `true` |
| `source` | string | 否 | 默认由首页传入 `homepage` |

## 返回体

成功：HTTP `200`

```json
{
  "ok": true,
  "message": "我们会根据您填写的信息与您联系。"
}
```

校验失败：HTTP `400`；模拟服务失败：HTTP `503`。

```json
{
  "ok": false,
  "message": "请填写正确的姓名。"
}
```

## 后端替换约定

- 保持路径、字段名、HTTP 方法和前端成功/失败结构不变。
- 真实接入时由服务端完成鉴权、限流、字段清洗、隐私合规、持久化和 CRM 转发。
- 不在浏览器端放置 CRM 密钥、数据库凭据或第三方服务密钥。
- 若返回结构需要扩展，保留 `ok` 和 `message`，避免破坏当前前端交互。
