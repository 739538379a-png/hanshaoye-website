# 汉少爷饭团官网：首页原型交接说明

## 当前版本

- 项目阶段：首个里程碑，移动端首页可用原型
- 当前分支：`master`
- 初版提交：`ddf57ba 生成初版`
- 技术栈：Next.js App Router、TypeScript、Tailwind CSS、Motion、Phosphor Icons
- 当前定位：前端展示与交互原型，后续由后端接入真实业务服务

## 前端已完成

- 移动端优先首页与桌面端响应式适配
- 视频首屏、播放/暂停、静音控制和静态封面回退
- 关于品牌、产品、制作、门店、合作和咨询模块
- 移动端导航抽屉、锚点导航和产品/门店横向画廊
- 合作咨询表单：姓名、手机号、意向城市、可选预算、隐私授权
- 本地模拟接口：`POST /api/cooperation-leads`
- 减少动态偏好、键盘焦点、错误提示和成功状态

## 后端接手重点

1. 保持表单字段和前端交互不变，替换接口内部实现。
2. 将本地模拟接口接入真实 CRM 或线索系统。
3. 增加服务端鉴权、频率限制、日志、数据脱敏和备份策略。
4. 在取得正式备案、隐私政策和业务审核结果后，再补充公开信息。
5. 不把 `90_内部参考_禁止公开` 或成本、合同、收益预测等资料放入公开构建产物。

## 启动与检查

```bash
npm install
npm run lint
npm run build
npm run dev
```

默认地址：`http://localhost:3000`。

## 目录说明

- `src/app/page.tsx`：首页结构
- `src/components/`：首屏、导航、表单和滚动显现组件
- `src/content/site-content.ts`：集中式页面内容配置
- `src/app/api/cooperation-leads/route.ts`：本地模拟接口
- `public/brand/`：品牌标识
- `public/media/`：已筛选的公开原型素材
- `docs/`：交接、接口与历史记录
